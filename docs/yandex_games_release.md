# Подготовка релиза в Яндекс Игры

Дата проверки: 2026-04-04

## Что уже исправлено под прошлые замечания

- Язык игры для `yandex` берется из Yandex Games SDK, ручной селектор языка скрывается.
- Русские тексты без смешения с английскими обновлены в игре и в `promo/metadata.json`.
- Награды в интерфейсе описаны явно:
  - в меню: `+3 токена`;
  - на экране результатов: `3 новые фигуры` и `удвоение токенов за раунд`.
- Требования к медиа зафиксированы, но сами скриншоты и видео нужно переснять отдельно из актуальной версии игры.

## Артефакт для загрузки

Собрать:

```powershell
npm run build:yandex
```

Для загрузки в Яндекс Игры нужно архивировать содержимое папки `dist/yandex`, чтобы `index.html` лежал в корне архива.

Эталонные значения полей карточки хранятся в `promo/metadata.json`.
Их лимиты и обязательные значения автоматически проверяются тестом `tests/yandex-metadata.test.ts`.

## Медиа

Текущие скриншоты и видео в репозитории считать устаревшими для модерации.

Что важно при следующей пересъемке:

- для десктопных скриншотов не менее 70% площади кадра должен занимать реальный геймплей;
- не использовать меню, настройки, темы и экран результатов как основные store-кадры;
- любые подписи на RU-кадрах должны быть полностью на русском;
- награда на кадрах и в видео должна быть очевидна из самого интерфейса.

## Проверка перед отправкой

Локально подтверждено:

- `npm test`
- `npm run build:yandex`

Перед финальной отправкой в модерацию осталось проверить уже в черновике Яндекс Игр:

- загрузку языка из SDK в реальной среде портала;
- rewarded и fullscreen рекламу в оболочке Яндекса;
- сохранение прогресса в аккаунтном storage;
- загрузку новых скриншотов и видео после их отдельного обновления.
